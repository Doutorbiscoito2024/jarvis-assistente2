J.A.R.V.I.S. 2.0 — pacote inicial funcional

O QUE ESTA VERSÃO FAZ
- Interface futurista adaptável ao celular.
- Comandos por texto.
- Reconhecimento de voz quando o navegador oferece Web Speech API.
- Respostas faladas com síntese de voz do navegador.
- Cálculos matemáticos básicos.
- Hora e data.
- Atalhos para abrir WhatsApp Web, YouTube e Google.
- Cache básico para abrir a interface offline depois da primeira visita.

O QUE AINDA NÃO FAZ
- Não possui IA generativa conectada.
- Não escuta continuamente a palavra "JARVIS" em segundo plano.
- Não controla configurações internas do Android nem outros aplicativos livremente.
- Não é um APK nativo; é uma aplicação web instalável (PWA).

COMO TESTAR
1. Extraia o ZIP.
2. Publique os arquivos na raiz do repositório GitHub Pages (não envie o próprio ZIP como site).
3. Abra o endereço do GitHub Pages no Chrome do Android.
4. Use o menu do Chrome > Adicionar à tela inicial / Instalar.
5. Permita o microfone quando solicitado.

OBSERVAÇÕES
- O reconhecimento de voz depende do navegador e pode exigir internet.
- O atalho do WhatsApp abre o WhatsApp Web; não envia mensagens automaticamente.
- Nenhuma chave de API está incluída.
- Não coloque senhas ou chaves secretas em arquivos publicados no GitHub.
- A integração de IA será feita após escolher um serviço compatível com as regras de idade e obter uma configuração autorizada.
